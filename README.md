# Bank Management System

A desktop-based Bank Management System developed using C++ and Qt Creator.

## Features
- Create a bank account
- Login using account number and PIN
- Check account balance
- Deposit and withdraw money
- View account details
- Change PIN
- Input validation and duplicate account number checking

## Technologies Used
- C++
- Qt Creator
- Qt Widgets
- File Handling

## How to Run
1. Download or clone this repository.
2. Open the project in Qt Creator.
3. Configure a compatible Qt kit.
4. Build and run the application.

**Note:** This project is for educational purposes. Use dummy account data only.
